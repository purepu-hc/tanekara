# たねから育てよう

条件を決めて植物を育てるブラウザ育成シミュレーションゲーム。
植える月・場所・土・肥料・水やりなどを選んで「育成スタート」。途中のイベントでも選択肢があり、結果は「枯れる／咲かない／咲く／満開・実る」に分かれます。

- アサガオ（種から・約半年）
- サクラ（種／接ぎ木苗／鉢苗・2〜5年）
- ユズ（ゆず湯のあとの実の種から・約10年／接ぎ木苗・約3年）
- アボカド（食べたあとの種から・約7年）
- チューリップ（秋植え球根・約8か月）
- スイセン（秋植え球根・2年目も咲かせる・約1年半）
- バラ（四季咲き・大苗／新苗・約1年）
- アジサイ（母の日の鉢を翌年、思った色に・約1年）
- 胡蝶蘭（お祝いの鉢をもう一度咲かせる・約1年）

気温は東京の平年値（1991〜2020年）をもとにした目安です。

## 構成

`index.html` 1ファイルのみ（ビルド不要）。植物の追加は `PLANTS` にデータを足すだけ。
